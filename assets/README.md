# assets/ —— 把生图 AI 的图接进来

这个页面**不需要改代码**就能换成"照片级"的画面：把图片按下表命名丢进这个文件夹，
刷新页面就会自动用图；没有图就继续用我画的 SVG 漫画兜底。

## 一、需要哪些图（最少 4 张）

| 文件名 | 用在哪 | 必须? |
| --- | --- | --- |
| `act1.png` | 第一幕 · 年初（3 个节拍） | ✅ |
| `act2.png` | 第二幕 · 先锋赛（2 个节拍） | ✅ |
| `act3.png` | 第三幕 · MSI 高歌／崩盘（3 个节拍） | ✅ |
| `act4.png` | 第四幕 · S 赛（3 个节拍） | ✅ |
| `act2-fmvp.png` | FMVP 那一拍（覆盖 act2） | 可选 |
| `act3-night.png` | 凌晨训练室那一拍 | 可选 |
| `act3-recover.png` | 复盘振作那一拍 | 可选 |
| `act4-cup.png` | 捧杯那一拍 | 可选 |

- 格式：`png` / `jpg` / `webp` 都行（同名只放一个）。
- 尺寸：**竖版 4:5**，建议 1024×1280 或更大。页面是 `object-fit: cover`，所以宁可
  头顶多留一点、底部多留一点（底部会盖一条字幕渐变）。
- 构图建议：半身、人物居中偏上、眼睛在画面上 1/3 处，别让头贴顶。

## 二、怎么出图（关键是"锁脸"）

平台（豆包 / 即梦 / 通义 / Nano Banana / Midjourney / SD+InstantID）都行，流程是：

1. 先找 **1 张 bin 哥脸部清晰的照片**当参考（正脸或 3/4 侧脸）。
2. 用「图生图 / 人物一致性 / 角色参考」把这张脸锁住，**不要用纯文生图**——纯文生图出来的一定不像。
3. 拿下面 4 段提示词一个个出图，风格前缀每次都带上，四张才像同一套剧照。
4. 出图后改成本表里的文件名，丢进本文件夹。

> ⚠️ 提示词里我没写真人姓名（多数平台会拦），你上传参考图即可。
> 也别让 AI 生成队标/赛事 logo，容易糊；要的话后期我自己叠矢量。

## 三、四段提示词（直接复制）

**通用风格前缀（每张都加在最前面）：**

```
电影级电竞赛场摄影，竖版 4:5 半身人像。主体是一名二十岁出头的中国男性电竞选手，
脸型偏圆、脸颊微胖、短黑发略带刘海、单眼皮、鼻翼略宽、笑起来嘴角上扬；
穿深蓝黑配色战队队服，领口有蓝色 V 形镶边。皮肤质感真实，浅景深，85mm 镜头，
边缘轮廓光，画面底部留出约 15% 的暗部空间用于放置字幕，人物头顶不要贴边。
```

**第一幕 · 年初（act1）**

```
（+通用前缀）场景：赛季开局的比赛舞台侧后方机位，背景是虚化的观众席与冷蓝色追光，
空气里有淡淡的烟雾。人物表情平静、略带拘谨，肩膀略收，双手自然垂在身前。
氛围：新人第一次上台，安静、有点紧张，冷蓝色为主色，低调光。
```

**第二幕 · 先锋赛 FMVP（act2 / act2-fmvp）**

```
（+通用前缀）场景：颁奖台正前方机位，头顶一束金色聚光灯打下来，背景是金色灯阵、
飘落的小彩带和虚化的欢呼人海。人物胸前挂着一枚发光金牌，自信微笑、下巴微抬。
氛围：封神时刻，金色为主色，高光是暖金，面部受光充足。
```

**第三幕 · MSI 崩盘（act3）**

```
（+通用前缀）场景：赛后舞台暗处，背景是虚化的红色警报灯和压下来的阴影，
远处有大屏的冷光。人物低着头，眼神空、嘴唇紧抿，脸颊上有汗，肩背下垂。
氛围：失误之后的那一刻，暗红+近黑为主色，顶光很硬，强烈的压迫感与孤独感。
```

**可选 · 凌晨训练室（act3-night）**

```
（+通用前缀）场景：凌晨三点的训练室，只有面前显示器发出冷蓝色光照亮半张脸，
背景全黑、隐约能看到电竞椅和机箱指示灯。人物眼睛熬红、神情疲惫但专注。
氛围：无人喝彩的深夜，冷蓝单光源，大量暗部，画质略带颗粒。
```

**可选 · 复盘振作（act3-recover）**

```
（+通用前缀）场景：训练室白天，暖白的窗光斜进来，人物侧身看向队友（队友在景深外虚化），
表情平静、眼神重新聚焦，手里拿着一支笔或战术板。
氛围：重新出发，暖白+浅蓝，画面比前两幕明亮、干净。
```

**第四幕 · S 赛捧杯（act4 / act4-cup）**

```
（+通用前缀）场景：世界赛决赛舞台正中央，金色雨从天而降，人物双手把金色冠军奖杯
举过头顶，仰头大笑、眼睛发亮，背景是漫天金色彩带与欢呼的人海剪影。
氛围：圆梦时刻，满屏金色与高对比，奖杯有强烈金属高光。
```

## 四、验证

放好图后打开页面，拖时间轴走一遍：能连续看到四张剧照 + 弹幕 + 色调变化就成功了。
如果在左上角看到的是我画的漫画小人，说明文件名或扩展名不对（大小写敏感）。
